小小 CNN 搭建师 · 免费体验课

一、在线体验
https://xiangsho1226.github.io/cnn.html
网页无需安装即可探索模块、调整参数、排序、检查连接、保存和导入积木方案。
未连接 Python 时，观察窗明确展示固定滤镜的教学预览，不生成训练成绩。

二、真实训练：老师电脑上运行 Python
下载“体验课源码.zip”，完整解压。请保留 cnn.html、cnn.css、cnn-core.js、cnn.js 和 cnn-backend 文件夹之间的目录关系。
需要 Python 3.10 或以上版本及首次安装依赖时的网络连接。建议 Python 3.12。
Windows 用户：进入 cnn-backend 文件夹，双击“启动体验课.cmd”。首次启动将创建独立 .venv 环境并下载 PyTorch CPU 等依赖。
看到服务已启动后，在同一台电脑的浏览器打开：
http://127.0.0.1:8000/
课程会自动连接同源后端。保持启动窗口开启，关闭窗口后训练服务停止。

也可以手动启动：
cd cnn-backend
python -m venv .venv
Windows 激活：.venv\Scripts\activate
macOS/Linux 激活：source .venv/bin/activate
python -m pip install "torch>=2.6,<3" --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python main.py

三、课程操作
1. 默认示例：卷积(8通道、3×3、保留边缘) → ReLU → 池化 → 展开 → 全连接(10输出)。
2. 点击任意积木，观察输入图片、输出尺寸和示范特征图。
3. 连接 Python，选学习轮数，开始训练。查看每轮真实训练损失和独立测试集准确率。
4. 训练后点选数字，观察网络预测，以及卷积/激活/池化层的真实特征图。
5. 修改一项参数后重新训练，与本页最近三次实验对比。更改方案后旧模型不会冒充新方案的训练结果。
6. 错误连接会得到中文提示：例如展开后无法再卷积，图片太小无法池化，最后一层必须输出10个类别。
7. “保存积木方案”只保存网络结构和轮数，不保存模型权重。浏览器自动保存当前结构，不保存学生身份。
8. “写一个数字，让 AI 猜猜”支持鼠标、手指和触控笔。先训练网络，再手写一个数字，点击“识别我写的数字”。清空可重写；预测也会更新观察窗的真实特征图。
9. 可上传不超过5MB、1600万像素的PNG/JPG/WebP数字图片。建议白底深色笔迹，仅包含单个数字0–9。图片在浏览器中裁切、居中、缩小为8×8；只发送64个像素值，不上传原始图片文件。该小模型不识别整页文字，手写风格不同可能认错。

四、数据与训练规则
数据集：scikit-learn 自带的 load_digits（1797张 8×8 手写数字），依赖安装后不需要另行下载图片。
固定随机种子42，分层划分1437张训练图片、360张测试图片。
优化器 Adam，学习率0.01，批次64，交叉熵损失。最多8轮、12层、100000个参数，每个服务同一时间运行1个实验。
测试图来自测试集，不是训练集；观察到的准确率不是对其他数据的泛化保证。
默认仅监听127.0.0.1。实验模型保存在服务内存中，重启丢失；最多保留12个实验，完成30分钟后可清理。

五、连接现有 GitHub 网页
右上角“连接 Python”可填写后端地址。GitHub Pages 不能运行 Python。
访问 GitHub HTTPS 页面时，部分浏览器会限制对本机或局域网 HTTP 服务的访问。推荐使用上面由 Python 提供的本机课程页面。
如果部署到云服务器，请使用 HTTPS 地址，并在 CNN_ORIGINS 中配置前端来源。
后端默认允许 https://xiangsho1226.github.io、http://127.0.0.1:8000 和 http://localhost:8000 的跨域请求。

六、教室共享与云端准备
课堂局域网共享示例（PowerShell）：
$env:CNN_API_TOKEN = '请改成你自己的随机长口令'
python main.py --host 0.0.0.0
学生从 http://老师电脑的局域网IP:8000/ 打开课程，并在连接窗口填写口令。不要把口令提交到公开仓库。
需要允许系统防火墙上的8000端口，并确认教室设备互通。连接口令只保留在当前网页内存中。
云端使用同一程序时也必须设置 CNN_API_TOKEN，使用1个进程，配置HTTPS反向代理；不要直接以无口令的 uvicorn main:app 对公网开放。
这是课堂体验原型：连接口令不替代商业平台的学生账号、订单权限、配额和班级隔离。尚未接入付费系统。

七、接口概要
如设置口令，以下API均带请求头 X-Lab-Token。
GET /api/health：检查服务
GET /api/samples：读取10张测试图片
POST /api/validate：检查结构，body示例见 示例方案.json
POST /api/train：发送layers、epochs（1/3/5/8）、seed（默认42），返回实验id
GET /api/jobs/{id}：获取状态、逐轮metrics、结构trace
POST /api/jobs/{id}/cancel：停止训练
POST /api/jobs/{id}/predict：发送{"pixels":[64个0到1的数值]}，返回digit、probabilities和features
只接受指定模块的JSON参数，不执行学生上传的Python代码。
